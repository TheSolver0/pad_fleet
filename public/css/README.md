# Fichiers Bootstrap (optionnel)

Pour utiliser Bootstrap en local au lieu du CDN :

1. Téléchargez et placez ici :
   - [bootstrap.min.css](https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/css/bootstrap.min.css)
   - [bootstrap-icons.min.css](https://cdn.jsdelivr.net/npm/bootstrap-icons@1.11.2/font/bootstrap-icons.min.css)  
     (et le dossier de polices `bootstrap-icons` associé)

2. Dans `login.html`, décommentez les lignes qui chargent `css/bootstrap.min.css` et `css/bootstrap-icons.min.css`, et commentez les lignes CDN.
