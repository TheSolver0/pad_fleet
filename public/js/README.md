# Bootstrap JS (optionnel)

Pour utiliser Bootstrap en local :

1. Téléchargez [bootstrap.bundle.min.js](https://cdn.jsdelivr.net/npm/bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js) et placez-le ici.

2. Dans `login.html`, décommentez la ligne qui charge `js/bootstrap.bundle.min.js` et commentez la ligne CDN.
